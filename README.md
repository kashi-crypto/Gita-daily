# Gita Daily

A simple Android app + home-screen widget that shows one Bhagavad Gita verse each day.

## Build it
1. Install Android Studio.
2. Open this folder as an existing project.
3. Let Gradle sync.
4. Choose your phone/emulator.
5. Press Run.
6. Long-press your home screen -> Widgets -> Gita Daily.

## Important
This is the recreated starter project. It currently contains 15 sample verses and the daily-rotation system.
The data layer is deliberately isolated in `GitaData.java`, so the complete 700-verse dataset can be added without redesigning the app.

Before publishing, use a translation/source you have permission to distribute and verify every Sanskrit/transliteration/meaning entry.
